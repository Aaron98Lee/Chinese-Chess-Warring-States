## How to review

1. Read **01** (5 minutes).
2. Go to **10 §1** and decide D1–D14. Every decision links back to its supporting document.
3. Dip into **04** and **06** for the historical and visual reasoning behind D1–D4.

## Labels used throughout

- **Evidence classes:** E1 direct evidence · E2 scholarly reconstruction · E3 reasoned interpretation · E4 artistic invention or convention.
- **Verification status:** V2 verified in this research pass · V1 existence or secondary confirmation only · V0 not yet verified (must be verified before design lock).
- **Board units:** `P` = distance between adjacent intersections.

## What this package does not contain

No code, no 3D assets, no concept images, no test results. These are produced only after approval, in the milestones described in document 09. Nothing in this package should be read as a claim that any asset, feature or test is complete.
